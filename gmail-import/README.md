# Gmail自動取り込み（即時利用通知メール）

カード会社から届く「ご利用のお知らせ」「利用速報」メールを、Google Apps Script が定期的にチェックして、
自動でカード家計簿アプリの明細に追加します。アプリを開く必要はありません。

メールの解析はAI（Gemini）が行うので、**特定のカード会社に限定されません**。件名に「利用」「決済」などの
言葉と「カード」「ペイ」などの言葉が両方含まれていれば、初めて見るカード会社のメールでもAIが内容を読んで
自動で明細に追加します（対応するカードもFirestore上に自動作成されます）。新しいカード会社を使い始めても、
このスクリプトを直す必要はありません。

---

## セットアップ手順

### 1. サービスアカウントを作成する（Google Cloud Console）

このアプリのデータベース（Firestore）に、Apps Script から直接書き込むための「鍵」を作ります。

1. https://console.cloud.google.com/iam-admin/serviceaccounts?project=sai-4d708 を開く
   （ログインは、カード家計簿アプリと同じ Google アカウントで）
2. 「サービスアカウントを作成」
   - 名前: 例）`card-tracker-gmail-import`
   - 作成して続行 → ロールで **「Cloud Datastore ユーザー」** を選択 → 完了
3. 作成したサービスアカウントをクリック →「キー」タブ →「鍵を追加」→「新しい鍵を作成」→ **JSON** を選択
   - JSONファイルがダウンロードされます（これが「鍵」です。他人に渡さないでください）

### 2. Gemini APIキーを取得する（メール解析用・無料）

1. https://aistudio.google.com/apikey を開く（同じ Google アカウントでログイン）
2. 「Create API key」→ 使うプロジェクトを選ぶ（なければ新規作成でOK）
3. 表示されたキー（`AIza...`から始まる文字列）をコピーしておく（あとで使います）

無料枠の範囲で十分動きます。

### 3. Google Apps Script プロジェクトを作る

1. https://script.google.com/ を開く（同じ Google アカウントでログイン）
2. 「新しいプロジェクト」
3. デフォルトの `Code.gs` の中身を全部消して、このフォルダの `Code.gs` の内容を貼り付け
4. コード上部の `FIRESTORE_USER_ID` を、アプリの「アカウントID」に書き換える
   - アプリを開く → ヘッダーの雲アイコン → 表示される「アカウントID」をコピーして貼り付け

### 4. 鍵とAPIキーを安全に設定する

1. Apps Script の画面左側の歯車アイコン（プロジェクトの設定）→ 一番下の「スクリプト プロパティ」
2. 「スクリプト プロパティを追加」を2回行う
   - プロパティ: `SERVICE_ACCOUNT_KEY` / 値: 手順1でダウンロードしたJSONファイルの中身を**そのまま全部**貼り付け
   - プロパティ: `GEMINI_API_KEY` / 値: 手順2でコピーしたAPIキー
3. 保存

### 5. 動作確認 & Gmailへのアクセス許可

1. Apps Script の画面上部の関数選択で `checkCardEmails` を選び、「実行」ボタン
2. 初回は「承認が必要です」と出るので、画面の指示に従ってGmailへのアクセスを許可
   - 「このアプリは Google で確認されていません」という警告が出た場合は、「詳細」→「（プロジェクト名）に移動」で進めます（自分で作ったスクリプトなので問題ありません）
3. 実行ログ（画面下部）を確認し、エラーが出ていないか確認
4. アプリを開いて、明細が追加されているか確認

### 6. 定期実行のトリガーを設定する

1. Apps Script の画面左側の時計アイコン（トリガー）
2. 「トリガーを追加」
   - 実行する関数: `checkCardEmails`
   - イベントのソース: 時間主導型
   - 時間ベースのタイマー: 分ベースのタイマー →「30分おき」程度がおすすめ
3. 保存

これで、新しい利用通知メールが届くたびに、最大30分以内でアプリに反映されるようになります。

## うまく取り込めない場合

- そのメールの件名に「利用」「決済」「ご請求」「お支払い」のどれかと、「カード」「ペイ」「Pay」のどれかが
  両方含まれているか確認してください（`Code.gs`内の`SUBJECT_ACTION_WORDS`/`SUBJECT_PAYMENT_WORDS`）。
  含まれていなければAIに解析させる対象にすらならないので、単語を追加してください。
- 件名の条件を満たしているのに取り込まれない場合は、AIが「購入確定の通知ではない」と判定しているか、
  解析エラーが起きている可能性があります。Apps Script の実行ログ（表示 → 実行数）で確認できます。
- 二重取り込みは、処理済みメールに自動で付く「カード家計簿-取込済み」ラベルで防いでいます。もし同じ明細が重複した場合は、片方をアプリ側で削除してください。
