# カード家計簿（CardManager Pro）

クレジットカードの利用額を毎月記録・管理できる React 製の家計簿アプリです。
Vite + React + Tailwind CSS + lucide-react + Firebase で構築されています。

## 主な機能

**ダッシュボード**
- 今月の合計利用額（前月比つき）
- 次回の支払い（日付・カード名・金額・あと何日）
- 今月残りの支払予定額
- カードごとの利用状況（グラデーションカードデザイン、利用枠ゲージ）
- 月別支出推移グラフ（全カード合計／カード別を切り替え可能）
- カテゴリ別支出内訳

**明細一覧**
- カード・カテゴリでの絞り込み
- 利用明細の記録・編集・削除
- JSON書き出し／読み込み、スクリーンショットからのOCR自動読み取り

**カード管理**
- カードの追加・編集・削除（ブランド・番号・名義・有効期限・デザインカラー・利用限度額）
- 締め日・支払日・支払日が土日の場合の調整（翌営業日／前営業日／調整しない）
- 引落口座（任意）
- 今年の累計・月平均、通常より支出が多い/少ない月の控えめな注記

**支払い予定**
- 支払予定一覧（支払日が近い順、全カード横断）
- 支払いカレンダー（月ごとに「いつ・どのカードから・いくら」を一覧表示）
- 引落口座別の今月の必要額

**ホーム画面に追加（PWA）**
- iOS: Safari で開き、共有ボタン →「ホーム画面に追加」
- Android: Chrome で開くと自動で「ホーム画面に追加」の案内が出ます（または右上メニューから）

## データの保存・同期

データは端末の `localStorage` にキャッシュされるほか、Firebase（Firestore）にも同期されます。
初回起動時に「この端末で新しく始める」を選ぶと匿名アカウントが作成され、既存のローカルデータは自動的にクラウドへ移行されます。
ヘッダーの雲アイコンからメールアドレス・パスワードを設定すると、他の端末からも同じデータにログインできます。

## セットアップ

```bash
npm install
npm run dev       # 開発サーバーを起動（http://localhost:5173）
```

## ビルド

```bash
npm run build      # 通常のビルド（dist/ に出力、GitHub Pages などの静的ホスティング向け）
npm run preview    # ビルド結果をローカルで確認
```

`dist/` を GitHub Pages や Netlify、Vercel などの静的ホスティングにそのままデプロイできます。

## 請求サイクルの計算について

各カードの「締め日」「支払日」の日番号を比較し、支払いが締め月と同じ月か翌月かを推定した上で、
実際の支払日・請求対象期間（前回の締め日の翌日〜今回の締め日）を計算しています。
土日にあたる場合の調整（翌営業日／前営業日）はカードごとに設定できますが、祝日の判定は行っていません
（誤った日付を自動生成しないため、あえて対象外にしています）。
