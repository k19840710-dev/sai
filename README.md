# sai — カード家計簿

クレジットカードの利用額を毎月かんたんに記録・確認できる家計簿アプリです。
ビルド不要の静的サイト（HTML / CSS / バニラ JavaScript）で、データは端末のブラウザ内（`localStorage`）に保存されます。外部サーバーへの通信は行いません。

## 主な機能

**ダッシュボード**
- 今月の支払予定総額（前月比・増減率つき）
- カード別ランキング（今月・先月・今年・全期間で切り替え）
- 月別支払額推移グラフ（全カード合計／カード別を切り替え可能、ホバー・タップで各月の金額を表示）
- カードをタップすると、そのカードの詳細画面（今月・先月・今年累計・月平均・過去最高・月別推移）を表示

**入力・明細**
- 利用日・カード・金額・カテゴリ・メモの記録
- 月ごとの一覧表示（前月・翌月への切り替え、月選択）
- 記録の編集・削除
- カードの追加・削除管理
- メモ／カテゴリ／カード名でのキーワード検索
- JSON ファイルへの書き出し（バックアップ）・読み込み（復元・マージ）

スマートフォン・タブレットにも対応したレスポンシブデザインです。

## 使い方

1. `index.html` をブラウザで開くだけで利用できます。
2. ローカルでサーバーを立てて確認する場合は、リポジトリのルートで例えば以下を実行してください。

   ```bash
   python3 -m http.server 8000
   ```

   その後ブラウザで `http://localhost:8000` を開きます。

3. GitHub Pages などの静的ホスティングにそのままデプロイすることも可能です。

## データについて

すべてのデータはブラウザの `localStorage` に保存されるため、別の端末・別のブラウザとは同期されません。機種変更やブラウザのデータ削除に備えて、画面上部の「書き出し」ボタンで定期的にバックアップ（JSON ファイル）を取得することをおすすめします。バックアップした JSON は「読み込み」ボタンから復元・マージできます。
